# Sasol Loyalty Customer Value & Opportunity Prediction

Competition project for the Sasol Customer Value challenge on Zindi.

## Objective
Predict customer-level outcomes over a 3-month forward-looking window (Dec 2025 – Feb 2026) for loyalty members:
1. `CLV_fuel`: Normalized, log-transformed fuel volume in litres ($z = \ln(1 + y) / s_{\text{fuel}}$). Evaluated by **RMSE** (Weight: 0.30).
2. `CLV_nonfuel`: Normalized, log-transformed non-fuel spend in ZAR ($z = \ln(1 + y) / s_{\text{nonfuel}}$). Evaluated by **RMSE** (Weight: 0.30).
3. `Opportunity`: Multi-class behavioral opportunity trajectory across 17 valid classes. Evaluated by **Weighted F1 Score** (Weight: 0.40).

$$\text{Final Score} = 0.30 \times \text{RMSE}_{\text{fuel}} + 0.30 \times \text{RMSE}_{\text{nonfuel}} + 0.40 \times \text{Weighted F1}_{\text{Opportunity}}$$
